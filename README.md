# Tileforge

Небольшой статический MVP движка для пошаговых игр. Можно открыть `index.html` напрямую
в браузере или запустить любой статический HTTP-сервер из корня репозитория.

## Что реализовано

- сетка из гексагонов или квадратов с настраиваемыми шириной и высотой;
- логические координаты `q, r`, отделённые от математического преобразования в экранные;
- вид сверху и изометрическая проекция;
- настраиваемые угол обзора изометрии, наклон плоскости игрового поля и кривизна сферы;
- поворот поля на 360° перетаскиванием ПКМ и автоматическое заполнение доступной области при любом размере сетки;
- базовые варианты ландшафта: равнина, холмы и сфера;
- перемещение объекта-маркера по ЛКМ на выбранную ячейку.

Основная геометрия и проекции находятся в `app.js`; проект не требует сборщика или
зависимостей, поэтому служит простой основой для последующей интеграции игрового цикла.
